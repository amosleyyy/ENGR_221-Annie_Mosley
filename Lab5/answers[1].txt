PART 1: Introduction to the assignment and code

1.1.a. How do draw_snowflake_recursive() and draw_snowflake_stack() draw a full snowflake?
Both methods draw a full snowflake by drawing one Koch-curve side three times. After each side, the turtle turns left 120 degrees to begin the next side of the triangular outline. The recursive version uses draw_curve_recursive() for each side. The stack version uses draw_curve_stack(), which processes drawing commands from a last-in, first-out (LIFO) stack.

1.1.b. How many “sides” of the snowflake does each initial call of draw_curve_recursive() and draw_curve_stack() draw?
Each initial call draws one side of the snowflake (one Koch curve). The full snowflake methods call the curve method three times to draw all three sides.

1.1.c. How does get_time_and_mem() find the total time that a method takes to run?
It records the starting time with time.perf_counter(), runs the function while memory_usage() samples memory use, and records the ending time. It calculates elapsed time by subtracting the start time from the end time. It estimates memory used by subtracting the lowest sampled memory value from the highest sampled memory value.

PART 3: Stack method pseudocode
(Submit this pseudocode in the Part 3 Canvas submission as well.)

draw_curve_stack():
    create a stack containing add_curve(initial length, initial depth)
    while the stack is not empty:
        remove the top command
        if the command is add_curve:
            if depth is less than 0:
                raise an error
            if depth equals 0:
                move the turtle forward by length
            otherwise:
                set third equal to length divided by 3
                push these commands in reverse execution order:
                    add_curve(third, depth minus 1)
                    turn right 60 degrees
                    add_curve(third, depth minus 1)
                    turn left 120 degrees
                    add_curve(third, depth minus 1)
                    turn right 60 degrees
                    add_curve(third, depth minus 1)
        if the command is turn_left:
            turn the turtle left by the command angle
        if the command is turn_right:
            turn the turtle right by the command angle

4.1.b. Explain why these results align with what the methods are doing “under the hood”.
The recursive method uses Python function calls. Each call keeps track of its current length, depth, and where execution should continue after the smaller calls finish. These active calls use Python's call stack. The stack-based method stores pending drawing operations in an explicit list and processes them one at a time, so it avoids recursive function calls. However, it still uses memory to store pending commands. The measured time and memory can vary with the computer, Python version, and measurement overhead.
