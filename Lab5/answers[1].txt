## Part 1: Understanding the Starter Code

**1.1.a. How do `draw_snowflake_recursive()` and `draw_snowflake_stack()` draw the full snowflake?**

Both functions draw a complete Koch snowflake by drawing three sides. Each side is drawn using its corresponding curve function. After drawing each side, the turtle turns 120 degrees so it can draw the next side. The recursive version uses recursive function calls to draw the smaller sections, while the stack version uses a stack to keep track of the drawing instructions.

**1.1.b. How many sides does each initial call to `draw_curve_recursive()` and `draw_curve_stack()` draw?**

Each initial call draws one side of the snowflake. Three sides are needed to complete the entire snowflake.

**1.1.c. How does `get_time_and_mem()` get the total time?**

The function records the starting time using `time.perf_counter()`. It then runs the drawing function while measuring memory usage. After the function finishes, it records the ending time. It subtracts the starting time from the ending time to calculate the total time taken.

## Part 2: Recursive Method

**Pseudocode for `draw_curve_recursive_helper()`:**

1. Check whether the depth is equal to zero.
2. If the depth is zero, move the turtle forward by the given length and return.
3. Otherwise, divide the length into three equal sections.
4. Recursively draw the first smaller curve.
5. Turn left 60 degrees.
6. Recursively draw the second smaller curve.
7. Turn right 120 degrees.
8. Recursively draw the third smaller curve.
9. Turn left 60 degrees.
10. Recursively draw the fourth smaller curve.

The recursive method keeps breaking the original line into smaller sections until it reaches depth zero. At that point, the turtle draws a straight line.

## Part 3: Non-Recursive Stack Method

**Pseudocode for `draw_curve_stack()`:**

1. Create an empty stack.
2. Add the original curve instructions to the stack.
3. Continue looping while the stack is not empty.
4. Remove the next instruction from the top of the stack.
5. If the instruction is a curve and its depth is zero, move the turtle forward.
6. If the depth is greater than zero, divide the length into three equal sections.
7. Add the smaller curve instructions and turning instructions to the stack in reverse order.
8. If the instruction is a left turn, turn the turtle left.
9. If the instruction is a right turn, turn the turtle right.
10. Continue until all instructions have been completed.

The stack method uses an explicit stack to keep track of the drawing instructions instead of using recursive function calls.

The recursive method may use additional memory because Python has to keep track of each function call. The stack method uses memory to store its drawing instructions.
