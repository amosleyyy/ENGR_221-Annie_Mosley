PART 1: Introduction to the assignment and code

1.1.a. How do draw_snowflake_recursive() and draw_snowflake_stack() draw a full snowflake?
Both methods draw a full snowflake by drawing one Koch curve side three times. After each side, the turtle turns left 120 degrees so that the next side forms the next edge of the equilateral-triangle outline. The recursive version calls the recursive curve method for each side. The stack version uses a list as a last-in, first-out (LIFO) stack to process drawing commands for each side.

1.1.b. How many “sides” of the snowflake does each initial call of draw_curve_recursive() and draw_curve_stack() draw?
Each initial call draws one side of the snowflake (one Koch curve). The full snowflake methods call the curve method three times to draw all three sides.

1.1.c. How does get_time_and_mem() find the total time that a method takes to run?
It records the starting time with time.perf_counter(), runs the function while memory_usage() samples memory use, and records the ending time. It calculates elapsed time by subtracting the start time from the end time. It estimates memory used by subtracting the minimum sampled memory from the maximum sampled memory.

draw_curve_recursive_helper(length, depth):
    if depth is less than 0:
        report an error
    if depth equals 0:
        move turtle forward by length
    otherwise:
        set segment length to length divided by 3
        draw a recursive curve of one third the length at depth minus 1
        turn right 60 degrees
        draw a recursive curve of one third the length at depth minus 1
        turn left 120 degrees
        draw a recursive curve of one third the length at depth minus 1
        turn right 60 degrees
        draw a recursive curve of one third the length at depth minus 1

PART 3: Stack method pseudocode (also submit this pseudocode on Canvas)

draw_curve_stack():
    create a stack containing add_curve(initial length, initial depth)
    while the stack is not empty:
        remove the top command
        if the command is add_curve:
            if depth is less than 0:
                report an error
            if depth equals 0:
                move turtle forward by length
            otherwise:
                calculate one third of the length
                push the commands in reverse execution order:
                    add_curve(third, depth - 1)
                    turn right 60 degrees
                    add_curve(third, depth - 1)
                    turn left 120 degrees
                    add_curve(third, depth - 1)
                    turn right 60 degrees
                    add_curve(third, depth - 1)
        if the command is turn_left:
            turn turtle left by the command angle
        if the command is turn_right:
            turn turtle right by the command angle

4.1.b. Explain why these results align with what the methods are doing “under the hood”.
The recursive method uses Python function calls. Each call must keep track of its current length, depth, and where it should continue after the smaller calls finish. These active calls use the program's call stack. The stack-based method instead stores the pending drawing operations in an explicit list and processes them one at a time. It avoids making recursive function calls, although it still needs memory to store pending commands. The measured time and memory can vary with the computer, Python version, and measurement overhead.
