# Lab 5: Recursion

## Description
This assignment focuses on recursion and stacks using Python.
The program draws a Koch snowflake using two different methods.

## Files
- snowflake.py: Contains the recursive and stack-based methods for drawing a Koch snowflake.
- answers.txt: Contains answers to the homework questions and pseudocode for both methods.
- README.md: Provides information about the assignment and how to run the program.

## Requirements
- Python 3
- memory_profiler
- Python Turtle

## How to Run
1. Open the Lab5 folder in Visual Studio Code.
2. Open the terminal.
3. Install memory_profiler using:

   python -m pip install memory_profiler

4. Run the program using:

   python snowflake.py

## Purpose
The purpose of this assignment is to understand recursion,
stacks, and the differences between recursive and
non-recursive programming.
