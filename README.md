# Lab 5 - Recursion and Stacks

## Description
This lab explores recursion and stacks by creating a snowflake using Python's turtle graphics.

## Files
- snowflake.py: Python program for drawing the snowflake.
- answers.txt: Answers to the lab questions and recorded results.
- requirements.txt: Required Python packages.

## How to Run
1. Install Python.
2. Install the required packages using:
   pip install -r requirements.txt
3. Run the program using:
   python snowflake.py
